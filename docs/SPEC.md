# 2D RPG 開発仕様書（基盤版）

このリポジトリでは、詳細仕様は `docs/rpg_spec_v0.2.md` に整理されている。フェーズ 1 では、エンジン部分と初期コンテンツを分離できるように、下記の基盤を整備する。

概要:
- Godot 4.7 / GDScript を前提としたプロジェクト設定
- `data/` の JSON を読み込む Autoload 群の基盤
- `tools/validate_data.gd` によるデータ検証の骨組み
- 仮タイトル画面とテーマ
- ロジック層の初期専用クラス

詳細なゲームルールやフェーズ条件については `docs/rpg_spec_v0.2.md` を参照する。
